# Integrări și exemple opționale

Niciuna dintre integrările de mai jos nu este instalată de acest template.
Compatibilitatea documentată pentru Codex CLI nu confirmă suportul în Cloud.

| Sursă | Ce merită folosit | Condiții înainte de activare |
|---|---|---|
| REA | Dovezi din binare și comportament livrat | Întrebare care nu poate fi rezolvată din sursă; instrumente și mediu compatibile; țintă autorizată. |
| Paperclip | Coordonare persistentă, sarcini, responsabilitate și bugete | Nevoie reală de orchestrare; server și stocare; conturi și costuri configurate separat. |
| OpenDesign | Spațiu colaborativ și sistem vizual | Nevoie de aplicația completă; capabilități de preview și mediu confirmate. |
| Archify | Renderer validat și export interactiv | Instalare și resurse complete, licențe păstrate; rulare verificată, nu presupusă. |
| diagram-design | Șabloane și exporturi avansate | Pachet complet și resursele sale; verificarea rezultatului exportat. |
| Taste Skill | Selecție vizuală și inspecție în browser | Cerințele runtime și browser din versiunea aleasă; licențierea activelor. |
| Composio | Catalog și acces la servicii | Alegerea integrării concrete, conturi, scopuri de acces și autorizarea acțiunilor. |
| Awesome LLM Apps | Exemple pentru aplicații AI și RAG | Verificarea exemplului concret, a licenței locale, dependențelor, datelor și costurilor. |

## Când proiectul devine o aplicație AI
Alege un exemplu după problema reală, nu după numărul de agenți.
Începe cu cel mai simplu flux complet: intrare → prelucrare → rezultat verificabil.
Pentru RAG, păstrează proveniența documentelor și verifică dacă citatele susțin
afirmațiile. Testează și lipsa unei surse relevante. Mai mulți agenți sau un graf
de cunoștințe nu sunt cerințe implicite ale template-ului.
Definește erorile, limitele de utilizare și evaluarea calității înainte de extindere.

În audit, README-ul exemplului knowledge_graph_rag_citations declară MIT, iar
rădăcina Awesome LLM Apps declară Apache-2.0. Nu am copiat codul acelui exemplu;
licența lui trebuie clarificată înainte de preluare. Adaptarea verificării de scop
provine separat din scope-creep-detector, care declară explicit Apache-2.0.

## Introducerea unei integrări
Verifică versiunea, licența componentei, cerințele runtime și capabilitățile reale.
Documentează datele trimise, accesul, costurile și metoda de dezactivare.
Configurează numai în limita cererii utilizatorului; nu transforma o listă de
resurse într-o instalare automată a tuturor serviciilor.
